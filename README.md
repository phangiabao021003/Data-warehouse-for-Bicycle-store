# Introduction
In this project, I implemented the data conversion process from the database of a Bicycle store chain, built the necessary Fact and Dim tables to serve the visualization process, built a dashboard to understand the business situation, and from there, develop strategies for the business. In addition, we also apply the Apriori algorithm, deploying a user interface for this algorithm to help users who are managers and strategists learn and understand customer consumption behavior.
